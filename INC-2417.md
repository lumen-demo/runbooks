# Runbook: INC-2417 checkout 500s after a deploy

Synthetic runbook for the Lumen Supply judging sandbox.

## Trigger

Checkout error rate climbs sharply right after a storefront deploy.

## First steps

1. Read the incident in the release-ops tooling (`get_incident`) and the current deployment (`get_deployment`).
2. Confirm the error rate and the current revision.
3. If the deploy is the cause, roll back to the previous healthy version using the exact current revision.

## Roll back

Use `rollback_deployment` with the current revision as `expected_revision` and the last healthy `previous_version` as
`target_version`. The incident moves to `mitigated` once the deployment is healthy again.

## After mitigation

- Capture a timeline in `/workspace/INC-2417.md`.
- Note the root cause and the fix in the report.
